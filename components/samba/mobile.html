Homelab files on Android

Access server files over Tailscale from Android’s document picker.

Download Android app

Download Homelab profile

  1. Connect Tailscale on your phone. Download and install the app above, allowing your browser to install it if Android asks.
  2. Download the Homelab profile. Open CIFS Documents Provider → Settings → Import settings.
  3. Enter the import password homelab, choose Append, and select homelab.cifs. This password only opens the credential-free profile.
  4. Edit each imported connection and enter your existing Samba password, then save. The server, username, share and SMB settings are already filled in.
  5. Open Android’s system file picker and select CIFS Documents Provider in the sidebar. Choose Homelab Downloads or Homelab Remote. You can open files directly or copy them to your phone using a file manager that supports document providers.

Downloads provides read-only access to the server’s /home/rishabh/Downloads. Remote is the existing read/write share.

The app is the unmodified, upstream-signed CIFS Documents Provider 2.4.0. Importing the separate profile is a one-time setup. No account password is included in either download.
